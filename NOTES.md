# Project Notes

## AI Tools

- Used Codex to scaffold the Angular implementation, iterate on UI styling, and add focused unit tests.
- Used TheSportsDB responses to verify endpoint shapes before typing API models.

## Design Decisions

- Chose Angular Material for reliable, accessible form controls and Angular-first integration.
- Used standalone components, typed API models, and service-level caching to keep the app small and testable.
- Styled the UI with SCSS and BEM class names for predictable component styles.
- Used a dark sportsbook-inspired theme while removing decorative navigation that was not part of the task workflow.
- Loaded badges automatically per visible league row so the list is informative without extra user actions.
